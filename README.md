# GTU

College coursework and practicals, GTU Computer Engineering.

## Setup

```bash
git clone https://github.com/Vishmayraj/GTU
cd GTU
```

Each subject keeps its own virtual environment and `requirements.txt`
(dependencies don't overlap much between subjects, so there's no point
sharing one venv for everything). `cd` into the subject folder you're
working on and follow the setup steps in its README, e.g. for PDS see
[`pds/README.md`](pds/README.md).

## Contents

- [`pds/`](pds/) -- Python for Data Science practicals (log analysis / anomaly detection project). See [`pds/README.md`](pds/README.md) for details.

More subjects will be added here as the semester progresses.
